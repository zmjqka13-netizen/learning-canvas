# HTML 质量线

只修改 `assets/html_template.html` 的版式；交互在 `assets/report.js`，渲染时整体内联。报告不加载 CDN、字体、脚本、样式、图片或网络接口。

## 渲染检查

- 由 `render_report.py` 生成；先 `--dry-run`，再核验回填后正式渲染。
- `@@…@@` 必须与渲染器的全部占位符一致；缺少/多出占位符退出 3。
- 用户数据按文本转义。仅解释 `**加粗**`、单反引号代码、`{S1}` 三类标记，不解释任意 HTML 或 Markdown 链接。
- 占位符只替换一遍；用户输入中的 `@@SCRIPT@@` 保持普通文本。
- 断言未核验时显著标红；无来源补充用灰底；旧结果不得沿用绿标。

## 功能与可达性

- 折叠帧、原生 details 自测答案、正文来源锚点均可通过键盘操作。
- 学习者复述区初始为空。保存和导出的内容只能来自学习者自己输入。
- 进度为“已自评完成的帧”，不把滚动距离或勾选伪称掌握率。
- 本地存储失败时显示提示；练习仍可继续，支持 JSON 导出。
- 手机宽度不横向溢出；焦点可见；支持减少动效偏好。
- JavaScript 关闭时原生折叠和来源仍可读；`--static` 生成不含脚本、答案展开的降级版。
- 打印时隐藏导航和按钮、展开帧与答案。用实际浏览器 PDF 检查，不只看 CSS 有没有 `@media print`。

## 验证方法

`tests/regression_suite.py` 用 HTML 解析器检查可执行标签与属性，不用 grep 数载荷。`tests/browser_smoke.cjs` 用实际浏览器验证自测、保存恢复、导出、离线、手机布局和打印，并保存截图。浏览器测试是可选开发依赖，不是技能运行依赖。
