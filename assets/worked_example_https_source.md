HTTPS 使用 TLS 保护浏览器与服务器之间传输的 HTTP 数据。

加密让传输中的数据难以被第三方直接读取。

完整性保护使传输中的数据被偷偷修改时能够被检测到。

服务器认证帮助浏览器确认通信对象，证书把公钥与域名关联起来。

HTTPS 不保证网站内容可信，也不能仅凭使用 HTTPS 就认定网站安全。
